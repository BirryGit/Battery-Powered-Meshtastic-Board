# Battery-Powered-Meshtastic-Board
This is an ESP-32-S3 powered LoRa board with a battery charger. It has a connected screen and external pins for I2C and power outputs. It has ESD protection.

I want to learn how to make PCBs, and this seemed like a good idea. I wanted to make my first PCB and understand the whole process. I want to get into meshtastic, so this is awesome :)
